## 2. 별도로 설치하는 의존성 (저장소에 포함하지 않음)

`pip install -r requirements.txt` 로 설치하는 패키지는 이 저장소에 들어 있지 않다. 각 패키지의 라이선스를 따른다.
2026-10-11 설치본 기준으로 직접 의존성은 모두 MIT·BSD·Apache 계열이다.

| 패키지 | 라이선스 |
|--------|----------|
| whisperx | BSD-2-Clause |
| faster-whisper, demucs, silero-vad, pysbd, noisereduce, deepmultilingualpunctuation, pyannote.audio, fastapi, pyyaml, ruamel.yaml | MIT |
| torch, torchaudio, av, click, uvicorn, python-dotenv, httpx | BSD |
| janome, openai, ffmpeg-python | Apache-2.0 |
| structlog | MIT 또는 Apache-2.0 |
| tqdm | MPL-2.0 AND MIT |

- 간접 의존성 `lameenc` (demucs 가 쓴다) 는 LGPL-3.0-or-later 다. 이 저장소는 패키지를 포함하거나 재배포하지 않는다.
  패키지를 묶어 배포(바이너리·컨테이너 이미지)하면 LGPL 의무를 따로 지킨다.
- ffmpeg 는 시스템에 설치된 실행 파일을 호출한다 (포함하지 않는다).
- 모델(Whisper, 정렬용 wav2vec2, pyannote, demucs, Silero VAD)은 실행할 때 내려받는다 (포함하지 않는다).
  pyannote 모델은 Hugging Face 에서 사용 조건에 동의해야 한다 ([docs/OPERATIONS.md](docs/OPERATIONS.md) 2절). 각 모델의 라이선스를 따른다.
- LLM 프로바이더(NVIDIA NIM, Gemini, OpenRouter, 구독 CLI 등)는 각 서비스의 약관을 따른다.
- 웹 화면 개발 도구(`web/package.json` 의 devDependencies: Vite, TypeScript, ESLint, Vitest, Playwright 등)는 배포물에 들어가지 않는다.
